# Nikhil Chougule — shevat_re

A modern, responsive personal creator portfolio website for **Nikhil Chougule (@shevat_re)**, showcasing his content, journey, collaborations, and social presence.

The website is designed around three core themes:

## 📖 About the Project

This portfolio website presents Nikhil Chougule's creator identity through a bold and minimal visual experience.

The website focuses on:

- 🏋️ Fitness and discipline
- 🏍️ Continental GT650 rides
- 🏡 Marathi lifestyle and family

- 🤝 Brand collaborations
- 📈 Creator journey and transformation
- 📩 Business enquiries
